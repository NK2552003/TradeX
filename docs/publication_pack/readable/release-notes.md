# Help Centre Release Notes

Guide | Updated 2026-11-09

Changes prepared on 9 November 2026 for the help, policy, consent and browser installation experience. These notes describe repository changes, not a production deployment announcement.

## Document library

The help centre now groups all 23 publication documents, supports full-text search and provides individual readable pages with section navigation. Public help links work without signing in. Source documents, reader assets and Markdown are generated together to reduce drift.

## Privacy choices

Added a versioned local preference record, reject-all and granular choices, a first-visit web notice and a persistent reopening action in help. Optional analytics, advertising, personalisation and affiliate attribution default off. Automatic affiliate attribution follows the saved choice.

## Installation

Added a browser-event installation bridge, user-triggered install action, a dismissible suggestion with a seven-day cooldown and platform-specific fallback instructions. The interface distinguishes unavailable prompts, accepted prompts and confirmed installation.

## Support and accuracy

Added the operator-provided support address and privacy-request instructions. Removed unsupported help-page production badges, release timing, market-latency and security claims. Existing ticket submission remains available only when a delivery callback is connected.

## Still to configure

Google AdSense serving, required certified CMP, production vendor/storage audit, legal approvals, business identity and retention arrangements remain release dependencies. Browser installation and optional consent do not enable these services. Verify the actual deployment before making availability claims.
