# Browser App Installation and Device Guide

Guide | Updated 2026-11-09

Install a browser-managed Alphajournal app when your browser supports it, or continue using the same service in a browser tab.

## Before installation

Open the legitimate Alphajournal site in a supported browser over HTTPS. Use the same account you normally use. Installation is optional and does not cost money, buy a subscription, accept cookies or grant notification, microphone or file permissions. The website remains usable without installation.

## Chrome and Edge

When the browser makes installation available, the app can show Install Alphajournal. Choose Install app to open the browser confirmation, then follow the browser instructions. You can also look for Install app in the address bar or browser menu. Menu labels vary by browser and operating system. A missing install action is not evidence that your account has a problem.

## iPhone and iPad

Open the site in Safari, use Share and choose Add to Home Screen where available, then confirm the name and add it. If you are inside a social or email app browser, first open the page in Safari. Browser and OS versions can change the available options; use their current installation guidance.

## Mac and other browsers

Supported Safari versions offer Add to Dock from the File menu. Other browsers may offer a site shortcut rather than a full installed web app. Use the browser menu if no automatic prompt is available. Native application downloads and app-store availability are separate from browser installation.

## Dismiss and try later

Choose Not now to suppress automatic install suggestions for seven days on this browser. Help and policies still provides installation guidance and a manual install button when a browser event is available. An accepted browser prompt is not shown as a confirmed installation until the browser reports installation. Standalone windows suppress the suggestion.

## Connectivity and updates

Signing in, syncing, fetching account data and most workspace operations require a network connection. This release does not promise offline editing or background synchronisation. Keep important work saved and verify sync before disconnecting. Updates normally load from the hosted service; reload after saving if an update is available. Do not clear storage to fix an issue before checking for unsynchronised work.

## Permissions and notifications

Installing does not grant notifications, microphone, camera or file access. Grant a permission only when intentionally using a feature that needs it. Browser and OS settings control revocation. A website permission and an in-app notification preference may both be required; neither is advertising consent.

## Uninstall and account deletion

Use your operating system or browser app manager to remove the installed app or shortcut. This does not cancel a subscription or delete the server account. To delete account data, use the in-app deletion controls and review the retention policy. Site data can remain after uninstall; clearing it can remove local settings and unsynchronised content.

## Troubleshooting

If Install app is unavailable, check whether the app is already installed, open it in a regular browser window instead of an embedded or private browser, and try the browser menu.
